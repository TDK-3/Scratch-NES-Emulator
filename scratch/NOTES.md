NES Emulator made with Goboscript / Scratch

Player 1: arrow keys, Z = A, X = B, Shift = Select, Enter = Start.
Player 2: I / K / J / L (up / down / left / right), U = A, O = B, H = Select, P = Start.
The Shift key needs TurboWarp.
Press Y while running to toggle the bottom-right debug overlay.
Press Q while running to paste a ROM hex string (convert .nes files at ./rom_string.html).
Press E while running in debug mode to halt and dump console state.
