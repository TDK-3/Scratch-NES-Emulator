NES Emulator made with Goboscript / Scratch

Press the green flag. The project first runs its shared-vector self test, then
boots the embedded game. Each finished frame is drawn in color with the Pen
extension by the display sprite. Set the pen_fit_to_screen variable to 1 to
scale the picture up to fill the screen; leave it at 0 for the original
pixel size. TurboWarp is the intended runtime; the
emulator is not expected to reach full speed yet.
