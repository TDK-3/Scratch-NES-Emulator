Loading it in Scratch

  1. Copy the byte text, or save it and open it in a text editor.
  2. Start the Scratch project and wait for a game to run.
  3. Press Q. The stage asks for the ROM byte values.
  4. Paste the text, press Enter, and the console reboots from it.

An empty answer cancels and keeps the running game. Only an image with the iNES signature and its full declared payload replaces the current one, and a Scratch list holds 200,000 items, so larger images are rejected.
